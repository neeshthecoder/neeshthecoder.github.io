# neeshthecoder.github.io

This is Avaneesh’s single-screen personal site, served by GitHub Pages at https://neeshthecoder.github.io/. It is plain static HTML and CSS with no build step; the only JavaScript is `scramble.js`, an optional decode effect on the name. As for styles, `styles.css` is the shared design system described in `STYLEGUIDE.md` and should not be edited, and `page.css` holds this page’s layout only. To add a project, open `index.html`, copy one `<article class="ps-card ps-card--sm">…</article>` inside `<section class="projects">`, change its label (e.g. `Project 03`), its link text and its `href`, then commit and push to `main`. No CSS changes are needed: the cards keep their size and gutter, and on narrow screens the row scrolls sideways instead of the page.
